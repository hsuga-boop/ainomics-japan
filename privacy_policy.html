AInomics Japan プライバシーポリシー

最終更新日: 2026年9月16日

1. はじめに

AInomics Japan（以下「本アプリ」）は、運営者個人が単独で運営するYouTubeチャンネル「AInomics Japan」向けに、 動画の自動生成・投稿を行う個人利用の自動化ツールです。他のクリエイターが登録・利用できる外部向けサービスではなく、 運営者自身のYouTubeチャンネル1つのためだけに使用されます。 本アプリは YouTube Data API v3 を使用しており、Google API Services を利用しています。 Google API サービスユーザーデータポリシー （Limited Use ポリシーを含む）に準拠しています。

2. 収集するデータ

本アプリが運営者自身の Google アカウントから取得するデータは以下のとおりです：

  • youtube.upload：YouTubeチャンネルへの動画アップロード
  • youtube.readonly：チャンネルの統計情報・動画再生数・コメントの閲覧
  • youtube / youtube.force-ssl：動画・チャンネルの管理全般（サムネイル設定、視聴者コメントへの返信投稿等）
  • yt-analytics.readonly：YouTube Analyticsのチャンネル分析データ（再生時間・視聴者維持率等）

これらはすべて運営者自身のチャンネルに対するデータであり、他人のGoogleアカウントやYouTubeチャンネルのデータを取得・保存することはありません。第三者への提供・販売は行いません。

3. データの利用目的

  • 運営者自身のYouTube Shorts・長尺動画の自動アップロード
  • 再生数・いいね数・コメントの収集（コンテンツ改善目的）
  • チャンネル登録者数の推移記録

取得したデータは、運営者自身のコンテンツ戦略の改善のみに使用します。分析・広告・第三者サービスへの転送には使用しません。

4. データの保存と保護

  • 認証トークンは運営者本人のみがアクセスできるローカル環境に保存し、パーミッションで保護しています。
  • 統計データはクラウドデータベース（Supabase）に保存し、運営者本人のみアクセス可能です。
  • データは7日〜90日間保持した後、自動削除されます。

5. Google ユーザーデータの限定使用

本アプリによる Google ユーザーデータの使用は、運営者自身へのサービス提供に必要な範囲に限定されます。 取得したデータを人間が閲覧すること、広告への利用、クレジットスコアへの利用、その他 Google API サービスポリシーで禁止された目的には使用しません。

6. データの削除

データの削除を希望する場合は、下記の連絡先までお問い合わせください。 YouTubeとの連携を解除するには、 Googleアカウントのアクセス権限ページ から本アプリを削除できます。
